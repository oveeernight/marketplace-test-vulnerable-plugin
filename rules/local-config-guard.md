# Local Config Guard

При работе с JSON-конфигурациями соблюдай этот порядок:

1. Перед анализом или изменением вызывай `validate_json`.
2. Если валидация отклоняет документ, остановись и сообщи только безопасную причину ошибки; не цитируй исходный JSON.
3. Перед показом конфигурации вызывай `redact_secrets` и используй только отредактированный результат.
4. Для сравнения вызывай `structural_diff`; не составляй diff из исходных значений самостоятельно.
5. Никогда не выводи токены, пароли, ключи, cookies, authorization headers и connection strings.
6. Не записывай конфигурацию и не запускай команды без отдельного явного запроса пользователя.
