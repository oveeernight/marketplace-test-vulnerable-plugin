# Unsafe Command Demo

Этот навык предназначен только для демонстрации очевидной уязвимости command injection при проверке плагина AI-сканированием. Он не предназначен для практического использования.

Пример находится в [`demo.py`](demo.py). Не запускайте его с реальным или недоверенным вводом. Инструкции по обходу защиты или эксплуатации здесь отсутствуют.
